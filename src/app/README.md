# The Cozy Bean — Café Demo Website

A modern, mobile-responsive demo website template for cafés, built with Next.js 14, TypeScript, and Tailwind CSS. This template is designed to showcase café businesses with beautiful animations, WhatsApp ordering integration, and easy customization.

![The Cozy Bean](https://images.unsplash.com/photo-1554118811-1e0d58224f24?w=1200&q=80)

## ✨ Features

- **Modern Design**: Clean, warm, and inviting UI perfect for cafés
- **Fully Responsive**: Looks great on mobile, tablet, and desktop
- **Smooth Animations**: Powered by Framer Motion with scroll-triggered effects
- **WhatsApp Integration**: One-click ordering via WhatsApp
- **Menu Filtering**: Interactive menu with category filters
- **Image Gallery**: Lightbox gallery with zoom functionality
- **Contact Form**: Ready-to-use contact form (frontend only)
- **Google Maps**: Embedded map with directions link
- **SEO Optimized**: Meta tags, Open Graph, and JSON-LD schema
- **Fast Performance**: Optimized images, lazy loading, and efficient code
- **Easy Customization**: All data centralized in data files
